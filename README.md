## 📋 Descripción del Proyecto

**Yuki-Bot MD** es un bot de WhatsApp versátil impulsado por `@whiskeysockets/baileys` y SQLite. Diseñado para ofrecer una experiencia interactiva y fluida en grupos y chats privados, cuenta con más de 342 comandos que incluyen sistemas de economía, entretenimiento, minijuegos, herramientas de utilidad, gestión de perfiles personalizados y multimedia.

---

## 🚀 Requisitos Previos

Asegúrate de tener instalado en tu entorno (PC o Termux):
* **Node.js** (Versión 18.x o superior recomendada)
* **Git**
* **FFmpeg** (Necesario para la manipulación de stickers y multimedia)
