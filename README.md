## 📋 Descripción del Proyecto

**Yuki-Bot MD** es un bot de WhatsApp versátil impulsado por `@whiskeysockets/baileys` y SQLite. Diseñado para ofrecer una experiencia interactiva y fluida en grupos y chats privados, cuenta con más de 339 comandos que incluyen sistemas de economía, entretenimiento, minijuegos, herramientas de utilidad, gestión de perfiles personalizados y multimedia.

---

## 🚀 Requisitos Previos

Asegúrate de tener instalado en tu entorno (PC o Termux):
* **Node.js** (Versión 18.x o superior recomendada)
* **Git**
* **FFmpeg** (Necesario para la manipulación de stickers y multimedia)
* **Yt-dlp** (Para la descarga de contenidos multimedia)

---

## 🛠️ Instalación y Arranque

Sigue estos pasos para clonar e iniciar el bot localmente:

1. **Clona el repositorio:**
   ```bash
   git clone [https://github.com/TU_USUARIO/yuki-bot-md.git](https://github.com/TU_USUARIO/yuki-bot-md.git)
   cd yuki-bot-md

Instala las dependencias necesarias:

    ```bash
    npm install
Inicia el bot:

   Modo desarrollo (con autoreinicio):

      ```bash
      npm run dev
   Modo producción / ejecución normal:

      ```bash
      npm start

⚙️ Tecnologías y Librerías Principales
Baileys (@whiskeysockets/baileys) - Conexión con la API de WhatsApp Web.

Node.js - Entorno de ejecución de JavaScript.

SQLite - Gestión ligera de base de datos para usuarios, niveles y perfiles.

Axios & Cheerio - Peticiones HTTP y web scraping para comandos interactivos.

FFmpeg & Yt-dlp - Procesamiento de audio, video y creación de stickers.
